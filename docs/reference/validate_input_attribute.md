# Check the input_args data of attribute_master()

Check the input_args data in attribute_master() and provides specific
warnings or errors if needed.

## Usage

``` r
validate_input_attribute(input_args, is_lifetable)
```

## Arguments

- input_args:

  `List` with the argument names and values entered in the function.

- is_lifetable:

  `Boolean` INTERNAL argument specifying if the life table approach is
  applied (TRUE) or not (FALSE)

## Value

This function returns warning or error messages if needed.
