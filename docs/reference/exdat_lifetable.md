# Population data per age and sex in Switzerland

This tibble contains population per age and sex for Switzerland.

## Usage

``` r
data(exdat_lifetable)
```

## Format

`exdat_lifetable`

- age_group:

  single year age groups

- sex:

  female or male

- midyear_population:

  mid-year populations

- deaths:

  annual deaths
