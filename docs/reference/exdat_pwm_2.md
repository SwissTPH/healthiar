# Geospatial outlines and populations of the Brussels-Capital region (Belgium)

This variable of class `sf` and `data.frame` contains the geospatial
outlines and populations of municipalities in the Brussels-Capital
region (Belgium).

## Usage

``` r
data(exdat_pwm_2)
```

## Format

`exdat_pwm_2`

- code:

  NIS-codes (i.e. unique statistical code assigned to each geographic
  area in Belgium)

- name:

  Dutch names of the municipalities

- population:

  municipality populations

- region:

  geographic position of each municipality (North, East, West, South)
  relative to Brussels (Center)

- geom:

  geospatial outlines of the municipalities (MULTIPOLYGON)
